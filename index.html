Comparison operators

A condition compares two values. The answer is always True or False.

OperatorMeaningExampleAnswer
==equal to5 == 5True
!=not equal to5 != 3True
>greater than7 > 10False
<less than2 < 9True
>=greater than or equal to3 >= 3True
<=less than or equal to4 <= 1False
Remember: = stores a value. == compares two values.

How if, elif and else work

score = int(input("Score out of 100: "))
if score >= 80:
    print("Excellent")
elif score >= 50:
    print("Pass")
else:
    print("Try again")
  • if checks the first condition.
  • elif means "else if". It checks the next condition only if the one before was False.
  • else runs when every condition above was False. It has no condition.
  • Python runs only one branch: the first one that is True.

Common mistakes

  • Using = instead of == in a condition. This gives a SyntaxError.
  • Forgetting the colon : at the end of if, elif or else.
  • Forgetting to indent the line under if. Use 4 spaces (Thonny does it for you).
  • Comparing a number from input() without int(). "90" >= 80 gives a TypeError.
  • Putting a condition after else. Only if and elif have conditions.
