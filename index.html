Teacher notes

Explain

One rule: one diamond = one if or elif. The True arrow goes to the indented lines under it. The False arrow goes to the next elif, or to the else.

The else has no diamond. It is just where the last False arrow ends.

Real life

A road junction with signs. At each junction (diamond) you either turn (True) or drive on to the next junction (False). If you pass every junction, you end up at the last stop (else).

Ask the class

  • "How many diamonds? How many if and elif lines?" (2 and 2)
  • Match 2, option B: "Try 35 degrees in this code. What prints?" (Warm. 35 >= 20 is True first, so Hot is never reached. Order matters.)
  • Option C: "Try 35. What prints?" (Hot and Warm. Two separate ifs can both run.)

Ask the class

Common bugs

  • Missing colon after if, elif or else.
  • = instead of == in the condition (SyntaxError).
  • print not indented under its if.
  • Typing Happy when the code checks "happy" (the else runs). Fix: .lower()
  • else with a condition: else mood == "bored": (SyntaxError)
